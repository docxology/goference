# Logging and visualization

[`pkg/utils`](../../active-goference/pkg/utils/) provides log streams,
elapsed-time logging, text traces, summaries, and chart and PNG helpers.
The `Log` and `Output` package globals serve the demos. Logger initialization
creates files relative to the working directory when the package is imported.
Run examples from a writable checkout or a disposable working directory.

See [CLI outputs](../guides/cli.md) and [example artifacts](../examples/README.md).
